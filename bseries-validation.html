Project Overview

This verification project served as a foundation benchmark for academic CFD reliability. By recreating exact geometrical parameters of historical Wageningen B-series profiles, simulations were validated directly against real physical data to confirm meshing strategy dependability.

Grid Independence Study

Conducted a strict grid convergence test utilizing multiple mesh sizes (coarse, medium, fine) to ensure the numerical data outputs remained completely independent of cell densities, achieving stable grid convergence index (GCI) metrics.
